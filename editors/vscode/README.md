# AxiomLang VSCode Extension & Live Flowchart Visualizer

Официальное расширение Visual Studio Code для языка программирования **AxiomLang** (`.axl`, `.axlui`, `.axmlui`).

## ✨ Ключевые возможности

1. **Органичное авто-построение блок-схем в реальном времени**:
   - Никаких ручных скобок или служебных разметок! Вы просто пишете код функций, ветвлений (`if/else`), циклов (`for..in`, `loop`) и операторов.
   - Схема генерируется на лету прямо при вводе текста (с дебаунсом 300 мс через `axiom_lsp`).
   - Автоматически строятся направленные стрелочки, обратные петли циклов, порты входов/выходов и ISO-совместимые фигуры:
     - 🔵 **Терминаторы** (овалы) — точки входа (`fn`) и выхода (`return`).
     - 🔶 **Условия** (ромбы) — ветвления `if/else` с разноцветными стрелками *True (зеленая)* / *False (красная)*.
     - ▱ **Ввод/вывод** (параллелограммы) — `print`, `println`, чтение потоков.
     - ⬛ **Процессы** (прямоугольники) — вычисления, присваивания, мутации переменных.
     - ⬡ **Циклы** (шестиугольники) — итераторы и диапазоны `for..in`.

2. **Двунаправленная интерактивность**:
   - **Следование за курсором**: перемещение курсора в коде мгновенно неоново подсвечивает соответствующий блок на блок-схеме.
   - **Клик по блоку**: кликните по любому узлу блок-схемы, чтобы курсор редактора мгновенно перешел на соответствующую строку в файле Axiom.
   - **Масштабирование и экспорт**: зуммирование (Zoom +/-, сброс) и экспорт чистого векторного SVG через команду `Axiom: Export Flowchart as SVG`.

3. **Синтаксическая подсветка TextMate**:
   - Подсветка ключевых слов (`fn`, `let`, `mut`, `struct`, `actor`, `cap`, `require` и их русскоязычных эквивалентов).
   - Подсветка пайплайн-оператора `|>`, оператора разворачивания ошибок `?`, системных возможностей (`cap Net`, `cap FS`).

4. **Интеграция с компилятором `axlc` и LSP**:
   - Живая диагностика Zero-Ambient безопасности.
   - Поддержка нативного автономного компилятора без сторонних серверов.

## 🚀 Установка

### Вариант 1: Символическая ссылка в каталог расширений VS Code
```bash
# Для стандартного VS Code
mkdir -p ~/.vscode/extensions
ln -s "$(pwd)/editors/vscode" ~/.vscode/extensions/axiom-vscode

# Для VS Code Server / Coder / Theia
mkdir -p ~/.vscode-server/extensions
ln -s "$(pwd)/editors/vscode" ~/.vscode-server/extensions/axiom-vscode
```

### Вариант 2: Сборка VSIX-пакета
```bash
cd editors/vscode
npx @vscode/vsce package
code --install-extension axiom-vscode-1.0.0.vsix
```

## 🛠 Использование
1. Откройте любой файл Axiom (например, `examples/06_functions.axl`).
2. В верхнем правом углу редактора нажмите иконку **Axiom: Open Live Flowchart Preview** или нажмите `Ctrl+Shift+P` -> `Axiom: Open Live Flowchart Preview`.
3. Пишите код — блок-схема будет автоматически перестраиваться и органично оживать на соседней панели!
