# AxiomLang

**AxiomLang** — строго типизированный язык системного программирования с верифицируемой безопасностью памяти и детерминированным временем отклика. 

Компилятор (`axlc_asm`) и пакетный менеджер (`axpm`) поставляются в виде легковесных бинарных файлов без внешних динамических библиотек и обращаются к ядру Linux через прямые системные вызовы.

---

## Что предлагает язык

- **Предсказуемая производительность**: Статически скомпилированный машинный код x86_64 с холодным стартом менее микросекунды и размером бинарников от нескольких килобайт.
- **Модель памяти Mandate Capability Arena (MCA)**:
  - Выделение памяти регионами через `sys_mmap` со смещением указателя (Bump Allocation) за $O(1)$ и выравниванием по 8 байт.
  - Контроль прав доступа на уровне блоков кода через мандаты (`CAP_MEM_READ`, `CAP_MEM_WRITE`, `CAP_MEM_GROW`).
  - Мгновенное освобождение памяти всего региона за $O(1)$ при выходе из области видимости без пауз на очистку.
- **Встроенный пакетный менеджер `axpm`**: Инициализация структуры проекта, разрешение локальных зависимостей, сборка и тестирование одной командой.
- **Штатная отладка через GDB / LLDB**: Автоматическая генерация отладочных таблиц DWARF (`.debug_line`) с точной привязкой машинных инструкций к номерам строк исходных файлов `.axl`.
- **Контроль инвариантов**: Встроенная статическая проверка диапазонов значений и защита от деления на ноль на этапе компиляции.

## Требования и сборка

Для сборки тулчейна из исходных текстов требуются стандартные системные утилиты `as` и `ld` (пакет `binutils`):

```bash
make
```

Команда создает в папке `bin/`:
- `bin/axlc_asm` — компилятор исходного кода `.axl`;
- `bin/axpm` — менеджер проектов и пакетов.

---

## Руководство по началу работы

### 1. Создание проекта
Создайте каркас нового проекта:
```bash
./bin/axpm init my_service
```

Команда сформирует манифест `axiom.pkg` и стартовый файл `src/main.axl`:
```axiom
require [Memory, IO]

intent "Production microservice"
cap memory [Scope: Arena, Max: 64KB]

fn main() {
    println("[✓] Service running under MCA memory model.")
}
```

### 2. Сборка и запуск
```bash
# Сборка проекта в бинарный файл
./bin/axpm build

# Непосредственный запуск собранного приложения
./bin/axpm run
```

### 3. Запуск тестов
```bash
./bin/axpm test
```

---

## Работа напрямую с компилятором `axlc_asm`

### Быстрый запуск файла
Скомпилировать и сразу выполнить программу в оперативной памяти:
```bash
./bin/axlc_asm examples/01_hello_world.axl -run
```

### Компиляция исполняемого файла
Собрать оптимизированный статический бинарник:
```bash
./bin/axlc_asm examples/01_hello_world.axl -o app
./app
```

### Отладка в GDB
Благодаря генерации секций DWARF исходный код доступен для пошаговой отладки:
```bash
gdb ./app
(gdb) break _start
(gdb) run
(gdb) stepi
```

## Набор верификационных тестов

Комплект эталонных тестов находится в каталоге `tests/pure_asm/`:

| Файл теста | Назначение |
| :--- | :--- |
| [`01_hello_world.axl`](tests/pure_asm/01_hello_world.axl) | Потоковый вывод строк (`sys_write`) и корректный код завершения (`sys_exit`). |
| [`02_mca_arena.axl`](tests/pure_asm/02_mca_arena.axl) | Выделение страниц памяти MCA, соблюдение лимитов и сброс арены за $O(1)$. |
| [`03_arithmetic.axl`](tests/pure_asm/03_arithmetic.axl) | Целочисленные вычисления, битовые операции и свертка констант. |
| [`04_actor_mandate.axl`](tests/pure_asm/04_actor_mandate.axl) | Изоляция контекстов акторов и передача сообщений по мандатам. |
| [`05_dwarf_debug.axl`](tests/pure_asm/05_dwarf_debug.axl) | Генерация отладочной информации и установка точек останова. |

Запуск всех проверок:
```bash
make test
```

## Структура репозитория

```text
AxiomLang/
├── bin/                 # Готовые бинарные файлы (axlc_asm, axpm)
├── src_asm/             # Исходный код ассемблерного тулчейна
│   ├── main.s           # Точка входа компилятора и обработка флагов CLI
│   ├── compiler.s       # Лексер, парсер и генерация инструкций x86_64
│   ├── mca_runtime.s    # Реализация арены памяти MCA (sys_mmap)
│   ├── debug/dwarf.s    # Генератор отладочных таблиц DWARF (.debug_line)
│   ├── axpm/            # Исходный код пакетного менеджера axpm
│   └── include/         # Константы системных вызовов и структуры памяти
├── tests/pure_asm/      # Эталонные верификационные тесты
├── examples/            # Примеры использования языка и алгоритмы
├── editors/vscode/      # Подсветка синтаксиса для VS Code
├── Makefile             # Сценарии сборки
├── README.md            # Документация (на русском языке)
└── README_EN.md         # Документация (на английском языке)
```
