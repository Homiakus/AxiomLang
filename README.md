# AxiomLang (axl) — Руководство для новичка и Архитектурная Спецификация

Добро пожаловать в **AxiomLang** — язык программирования нового поколения, созданный специально для безопасных, математически доказуемых и сверхбыстрых операционных систем и программ.

---

## 🌟 1. В чем главная идея? (Простыми словами)

В обычных языках программирования (C++, Python, Go):
* Программа, запущенная на компьютере, по умолчанию «видит» весь компьютер: может попытаться прочитать любой файл, выйти в интернет или занять всю оперативную память.
* Если в программе есть ошибка или зловредный код, она может навредить всей системе.
* Скомпилированные программы легко вскрыть и взломать с помощью декомпиляторов (IDA, Ghidra).

В **AxiomLang**:
1. **Принцип «Нулевого доверия» (Zero-Ambient Authority):** Программа изначально «слепа и глуха». Чтобы записать файл, нарисовать окно или отправить байт в сеть, программа должна явно объявить свой **Намерение (Intent)** и получить от операционной системы цифровой ключ — **Мандат (Capability)**.
2. **Память без тормозов и утечек:** Здесь нет «мусорщика» (Garbage Collector), который внезапно замораживает программу, но при этом невозможно случайно повредить память.
3. **Математическая броня от взлома:** Скомпилированный бинарный код запутывается с помощью высшей математики (топологические узлы и криптографические решетки LWE). Декомпилятор видит не код, а неделимое математическое уравнение.

## 🚀 2. Как выглядит код на AxiomLang?

### Пример 1: Hello World
```axiom
// Запрашиваем у ОС право писать в консоль
require cap[Console.Out]

intent "Вывод приветственного сообщения" {
    print("Привет, мир! Это программа на AxiomLang.")
}
```

### Пример 2: Безопасная работа с файлами
```axiom
// Запрашиваем мандат на запись строго в один файл
require cap[FileSystem.Write("/data/user.json")]

intent "Сохранение настроек" {
    let payload = { user: "Admin", theme: "GlassDark" }
    fs.write("/data/user.json", payload)
}
```

## 📂 3. Структура проекта в `/home/den/AxiomLang`

* **`cmd/axlc/`** — Исходный код компилятора и транслятора (`axlc`).
* **`stdlib/`** — Стандартная библиотека языка:
  * `gui/` — Сверхбыстрый движок интерфейсов (120 FPS, эффекты стекла и блюра).
  * `fs/` — Мандатная файловая система без скрытых уязвимостей.
  * `data/` — Колоночные таблицы (DataFrames) со скоростью обработки миллиарды операций в секунду.
  * `crypto/` — Квантово-устойчивые алгоритмы и доказательства переходов.
  * `actor/` — Модель изолированных легковесных акторов без блокировок.
* **`examples/`** — Примеры готовых программ для быстрого старта.
* **`docs/`** — Полные спецификации, таблицы бенчмарков и математические доказательства.

## 🛠️ 4. Как скомпилировать и запустить программу?

1. Перейдите в папку с проектом:
   ```bash
   cd /home/den/AxiomLang
   ```
2. Скомпилируйте и запустите пример:
   ```bash
   go run cmd/axlc/main.go -run examples/01_hello_world.axl
   ```
3. Компиляция в готовый защищенный бинарник:
   ```bash
   go run cmd/axlc/main.go -o my_app -protect examples/01_hello_world.axl
   ```
